Séance 1 : les bases

Types

Type Nom Python Exemple
texte str "bonjour"
entier int 42
décimal float 3.14

Conversion : str(14) → "14" ; int("14") → 14 ; float(14) → 14.0 ; int(3.99) → 3 (tronque, n'arrondit pas)

Variables

nom = valeur range une valeur dans une variable (= n'est pas une égalité mathématique, ça se lit « mets... dans... »). Réassigner une variable écrase l'ancienne valeur.

print

Séance 2 : les fonctions

def nom_fonction(parametre1, parametre2):
    # corps, indenté de 4 espaces
    return resultat
  • Définir (def ...:) n'exécute rien. Appeler (nom_fonction(valeurs)) exécute le code.
  • paramètre = nom utilisé dans la définition. argument = valeur donnée au moment de l'appel.
  • L'ordre des arguments compte.
  • return valeur renvoie un résultat réutilisable (stockable dans une variable, recalculable). print(...) affiche seulement à l'écran, puis c'est perdu.
  • Une fonction sans return renvoie None (aucun résultat ; None + 1 provoque une erreur).
  • Après un return, la fonction s'arrête immédiatement : les lignes suivantes ne s'exécutent jamais.
  • Valeur par défaut : def f(x, y=1): rend y optionnel à l'appel. Les paramètres avec valeur par défaut se placent après ceux qui n'en ont pas.
  • Une variable créée à l'intérieur d'une fonction n'existe pas à l'extérieur.
  • Docstring : """texte""" juste sous le def, décrit la fonction, affichée par help(fonction).

Séance 3 : les conditions

if condition:
    ...
elif autre_condition:
    ...
else:
    ...

Comparateurs : == != < > <= >= (= assigne une valeur, == compare et renvoie True/False, ne pas confondre).

and (vrai si les deux le sont), or (vrai si au moins un l'est), not (inverse vrai/faux).

Piège fréquent : age == 18 or 19 ne teste pas ce qu'on croit (19 seul est toujours vrai). Il faut répéter la comparaison : age == 18 or age == 19.

Python teste les elif dans l'ordre et s'arrête au premier vrai : un test trop large en premier empêche les suivants d'être atteints.

Comparer du texte compare l'ordre alphabétique, caractère par caractère (toutes les majuscules sont considérées avant toutes les minuscules).

Dans une fonction, si le if fait déjà un return, pas besoin d'un else après : si on continue, c'est que la condition était fausse.

Séance 4 : les boucles while

while condition:
    ...   # répété tant que la condition reste vraie
  • Il faut toujours quelque chose qui rapproche la condition de devenir fausse (i += 1, n -= 1...), sinon boucle infinie.
  • Compteur : i = 0 avant la boucle, i += 1 dedans.
  • Accumulateur : total = 0 avant la boucle (jamais réinitialisé dedans), total += ... à chaque tour.
  • break : sort immédiatement de la boucle, sans finir le tour ni retester la condition.
  • continue : passe directement au tour suivant. Attention : un continue placé avant la ligne qui fait avancer le compteur crée une boucle infinie.
  • while True: suivi d'un break conditionnel : motif courant pour « répéter jusqu'à ce que ».
  • Une boucle peut être imbriquée dans une autre : la boucle intérieure refait tous ses tours à chaque tour de la boucle extérieure.

Séance 5 : les listes et l'indexation

Créer et accéder

liste = [a, b, c] : indices à partir de 0. liste[-1] = dernier élément, liste[-2] = avant-dernier.

len(liste) = nombre d'éléments (dernier indice valide = len(liste) - 1).

liste[i] = nouvelle_valeur modifie l'élément à l'indice i (une liste est modifiable, contrairement à une chaîne).

Slicing (découper)

liste[i:j] = éléments de l'indice i jusqu'à j exclu.

liste[:3] = les 3 premiers ; liste[3:] = à partir de l'indice 3 ; liste[-2:] = les 2 derniers.

Marche pareil sur les chaînes : mot[0], mot[1:3], mot[-1].

Méthodes de liste (modifient la liste directement, ne renvoient rien d'utile)

Méthode Effet
liste.append(x) ajoute x à la fin
liste.pop(i) enlève (et renvoie) l'élément à l'indice i
liste.remove(v) enlève la première occurrence de la valeur v
liste.sort() trie sur place, ordre croissant
liste.sort(reverse=True) trie sur place, ordre décroissant
liste.index(v) indice de la première occurrence de v

Piège : x = liste.sort() met None dans x (.sort() ne renvoie rien ; c'est liste elle-même qui est triée).

Fonctions qui ne modifient rien, renvoient un résultat

len(liste), sum(liste), min(liste), max(liste).

sorted(liste) renvoie une nouvelle liste triée sans toucher à l'originale ; sorted(liste, reverse=True) pour l'ordre décroissant.

Chaînes de caractères

mot.upper(), mot.lower() renvoient une nouvelle chaîne, l'originale n'est pas modifiée. Une chaîne ne se modifie pas par indice (mot[0] = "P" provoque une erreur), contrairement à une liste.

Listes et fonctions

Une liste peut être un argument de fonction, ou une valeur renvoyée. Une fonction peut renvoyer plusieurs valeurs à la fois : return a, b, récupérées avec x, y = fonction(...).

Construire une liste avec une boucle :

resultat = []
i = 1
while i <= n:
    resultat.append(i * i)
    i += 1
